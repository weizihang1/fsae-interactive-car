## 1. 制动系统

### 1.1 第一层：规则红线（不参与优化，只参与满足）

来自 T 6 / T 3.20 / T 10：

| 条款 | 要求 |
| --- | --- |
| T 6.1.1 | 液压制动、作用四轮、**单一控制** |
| T 6.1.2 | **两套独立液压回路**，各自独立油壶；任一点泄漏后仍须保证至少两轮有效制动 |
| T 6.1.3 | 密封防漏 |
| T 6.1.7 | 禁止未包覆的塑料刹车管 |
| T 6.1.8 | 须防护动力总成失效、运动件干涉与轻微碰撞 |
| T 6.1.10 | 踏板（含传力面与安装座）**必须承受 2 kN 不失效**；踏板箱须牢固安装在主结构上 |
| T 6.1.11 | 踏板必须用钢或铝制造（或机加钢/铝/钛） |
| T 6.1.12 | 可调踏板必须有正限位，防止松动脱出 |
| T 6.1.13 | 前 90% 踏板行程可用于能量回收，剩余行程必须直接驱动液压 |
| T 6.2 | 必须装 BOTS 过行程开关；任一回路失效时踏板过行程须断开 SDC；**驾驶员不得能复位** |
| T 6.3 | 刹车灯：红色、后向清晰可见、侧视位于轮心线与驾驶员肩高之间、后视大致居中 |
| T 3.20.1 | 踏板、主缸、液压油壶必须在 AIP（前撞击结构）**后方** |

### 1.2 第二层：设计优先级（按次序）

**① 安全与冗余** —— 双回路、2 kN 踏板箱、BOTS。这一层没有取舍空间。

**② 前后制动力分配（brake bias）** —— 直接决定制动距离与制动稳定性。

报告实例（μ=0.7，质心高 300 mm，轴距 1590 mm，前轴距 923.5 mm，总重 2992 N）：

```
动态前轴载荷 Wf = w·Lr/L + w·μ·h/L = 1646.56 N
动态后轴载荷 Wr = w·Lf/L − w·μ·h/L = 1342.65 N
整车制动力   Fb = μ·w        = 2094.44 N
```

注意动态载荷转移：μ=0.7 时前轴载荷比静载增加了约 24%，
这正是需要平衡杆（balance bar）或比例阀来跟随理想分配曲线的原因。

**③ 卡钳夹紧力需求** —— 由力矩平衡反推，报告得前卡钳需 **3650 N**、后卡钳 **2480 N**。

**④ 卡钳选型** —— 报告的选型判据次序是：
**活塞数量 → 活塞面积 → 重量 → 可得性**。
最终选 Wilwood GP200（2 活塞浮动式、整铝机加、1.23 in² 活塞面积、仅 0.9 lbs，
而多数同类超过 1.8 lbs）。轻量化在这里被当作主要卖点。

**⑤ 制动盘直径** —— 受轮辋限制（报告为 11 寸轮辋内）。直径定死后，
提升制动力的手段只剩夹紧力与摩擦系数。

**⑥ 踏板箱与人机** —— 踩踏力、行程、平衡杆调节范围、可调性与正限位的矛盾。

**⑦ 热管理与耐久** —— 盘温、刹车片磨损、通风。

## 2. 转向系统

### 2.1 第一层：规则红线（T 2.8）

| 条款 | 要求 |
| --- | --- |
| T 2.8.1 | 禁止拉索或皮带驱动转向 |
| T 2.8.2 | 方向盘必须**直接机械驱动**前轮 |
| T 2.8.3 | 必须有**正限位**，且限位必须**布置在齿条上**；须防止轮胎与轮辋碰到其他部件；静止状态下必须能转向 |
| T 2.8.4 | 方向盘处总自由间隙 **≤ 7°**；驾驶员施加正常转向力时不得有过大变形 |
| T 2.8.5 | 方向盘必须用**快拆**连接转向柱，驾驶员戴手套在正常坐姿下可操作 |
| T 2.8.6 | 方向盘不得位于前环后方超过 **250 mm**（水平、车辆中线测量） |
| T 2.8.7 | 方向盘轮廓必须连续、近似圆形或椭圆、**不得有凹段** |
| T 2.8.8 | 任意角度下方向盘顶部不得高于前环最高面 |
| T 2.8.9 | 齿条必须机械连接到主结构；所有固定件须在翻滚保护包络内 |
| T 2.8.10 | 方向盘到齿条之间所有接头必须是机械连接且在技术检查时可见 |
| T 2.8.11 | 允许电控后轮转向，但机械限位须把后轮转角限制在 **6°** 以内 |

### 2.2 第二层：设计优先级

**① 规则合规与安全** —— 正限位、7° 间隙、快拆、包络。

**② 驾驶疲劳** —— 这是报告里被明确点出的**首要设计目标**：
"overcomes the major issue of most formula student cars during endurance events
i.e. drivers fatigue"。耐力赛中驾驶员体力是限制因素，转向力必须低。

**③ 转向力 ↔ 响应的折衷** —— 报告原文：
转向力越低越理想，但低转向力必然带来响应变慢、全锁时方向盘转角过大。
报告把**锁到锁定为 360°**，以此反推转向臂力臂长度与齿条选型。

**④ 阿克曼策略** —— 报告选择**反阿克曼（Anti-Ackermann）**，理由有两条：

- 齿条前置、转向臂朝前时，外轮转弯半径小于内轮，本身就是阿克曼的反向；
- 高速时阿克曼会让内轮滑移角偏大、升温并产生拖曳阻力；
  反阿克曼可降低滑移、把抓地力更多给弯外侧轮胎。

**⑤ 齿条齿轮选型** —— 优点：反馈量大、手感直接、无间隙；
缺点：**不可调**，一旦磨损出间隙只能整体更换（需要把它当作耗材设计）。

**⑥ 方向盘人机与快拆** —— 报告用**铝激光切割**减轻重量以降转向力，快拆沿用上一年度件。

**⑦ 具体参数（报告实例，可作量级参照）**

```
轴距            1590 mm
王销间距        1147.70 mm
阿克曼角        14.00°      （tanφ = 1147.70 / (2 × 1590) = 0.3609）
内轮最大转角     25.13°
最小转弯半径     3389.66 mm  （= 轴距 / tan 25.13°）
拉杆长度         391.72 mm
小齿轮半径       15 mm
转向臂力臂       92 mm
拉杆力           456.44 N    （= 41993 N·mm / 92 mm）
齿条力           450 N       （拉杆力 × cos 9.64°）
小齿轮力矩       6750 N·mm
方向盘力矩       7500 N·mm   （效率 90%）
驾驶员转向力     15 N        （方向盘半径 0.5 m）
```

## 3. 对建模的直接含义（紧固件规范）

来自 T 10，这些是可以直接落到零件上的硬指标：

| 条款 | 对模型的要求 |
| --- | --- |
| T 10.1.2 | 关键紧固件必须**钢制、≥M4、8.8 级以上**（未改原厂件可 3 mm） |
| T 10.1.3 | 类型只允许**六角头螺栓（ISO 4017 / 4014）或内六角圆柱头螺钉（ISO 4762 / DIN 7984 / ISO 7379）** |
| T 10.2.1 | 必须用防松措施，**尼龙锁紧螺母（ISO 7040 / ISO 10512 / EN 1663）**等 |
| T 10.2.4 | **锁紧螺母之外至少露出两圈完整螺纹** |
| T 10.2.5 | 转向/悬架上的球头关节轴承必须有大于轴承座内径的挡圈或垫片做保持 |
| T 10.2.6 | **可调拉杆端必须用锁紧螺母约束**，防松动 |

这几条解释了为什么参考图里是一套完整的关节轴承 + 尼龙锁紧螺母 + CNC 拨叉：
那不是画着好看，而是规则逼出来的结构。

## 4. 我们当前模型的差距

对照上面两节，模型现在的缺口是：

1. **制动**：只有制动盘与卡钳示意件，**没有踏板箱、平衡杆、双主缸、油壶、刹车管、BOTS、刹车灯**。
   这是最大缺口，也正好是参考图展示的那套总成。
2. **转向**：有齿条、齿条壳、转向柱、方向盘、转向拉杆，但**没有齿条上的正限位、
   没有快拆结构、没有锁紧螺母、没有齿条齿轮的齿形细节**。
3. **紧固件**：完全没有。规则要求的 M4 8.8 六角螺栓/内六角螺钉、尼龙锁紧螺母、
   露出的两圈螺纹，一个都没建。
4. **球头轴承**：悬架叉臂现在是一根光管直接连到车架，**没有关节轴承与锁紧螺母**。
5. **件号体系**：没有。参考图里每个零件都有件号（GFM-0810-10、CNC-2-24、HRT_26B）。
